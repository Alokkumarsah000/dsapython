#  Q1: what is time complexitY?
**Answer:**  rate of increase in time with respect to input size.

### Big O() notation
- used to calculate time complexity.
- O(time taken)

## how to calcuate time complexity?

- time complexity is always calcuated in terms of worst case
- avoid constant
- avoid lower bound


## there are 3 cases to calculate time complexity
- best case [omega notation]
- average case [theta notation]
- worst case [Big o notation]

# space complexity

- space taken to calculate problem
- Big oh notation is used to calcualate space complexity
- two types of space
    - input space : space used to store input
    - extra space : extra space used to solve problem
